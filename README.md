### 🚀 Featured Projects

#### 💽 Discogs ETL Pipeline
An end-to-end data engineering project designed to extract and process comprehensive music metadata.
* **Tech:** Python, Pandas, Requests, SQLAlchemy, SQL, Supabase, Looker, Git.
* **Impact:** Built a robust, automated pipeline that successfully pulls raw API data, transforms it into clean relational datasets, and pushes it to a cloud Supabase environment for advanced BI visualization in Looker.

#### ⚙️ Full-Stack Admin Console
A centralized administrative dashboard developed for managing complex database operations.
* **Tech:** FastAPI, Python, SQLAlchemy, Azure DB, MS SQL, HTML, CSS, JS.
* **Impact:** Engineered a secure backend architecture using FastAPI to interface dynamically with Microsoft Azure DB and MS SQL, fully integrated with a custom-coded responsive frontend.

#### 👑 Queen History Platform
A frontend web platform celebrating the history, discography, and legacy of the rock band Queen.
* **Tech:** HTML, CSS, Vanilla JS.
* **Impact:** Delivered a manually configured, highly tailored web experience focused on clean code, layout control, and deep-dive historical research without relying on automated site builders.
